# Воуки — кейс №2 — презентационный лендинг V6

Лендинг команды «Воуки» для отбора на хакатон {Sib}Код.

## Изменения V6
- Убраны служебные оговорки о статусе согласования, гипотезах и внутреннем процессе.
- Формулировки заменены на пользу, принципы работы и проверяемые результаты.
- Вместо таблицы с юридическими комментариями — ясная схема того, как предлагаем разграничивать доступ.
- Вопросы заказчику сформулированы языком презентации, без P0/P1 и англоязычных внутренних ярлыков.
- Структура из пяти разделов, анимация вопросов в хедере и вкладки трёх участников сохранены.
- Интерактивная лаборатория отсутствует (удалена ещё в V5).

## Состав
- `standalone.html` — автономный лендинг
- `index.html` + `styles.css` + `app.js` — раздельные исходники
- `DESIGN.md` — визуальная система

## Границы
Концепция, а не внедрённая платформа. Примеры демонстрационные. Конкретные соглашения по данным и условия кампаний находятся среди вопросов заказчику. Эти уточнения находятся здесь, а не на публичных экранах.

Видео V2 не пересобиралось и намеренно не включено в пакет: его экранные тексты не соответствуют новой версии лендинга.
